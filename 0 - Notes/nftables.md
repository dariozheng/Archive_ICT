**nftables** is the modern Linux kernel packet classification framework. 

A **Linux kernel packet classification framework** is the underlying software architecture inside the Linux operating system core that inspects, categorizes, and directs network data packets based on predefined rules.

It serves as the engine for firewalls, routing, network address translation (NAT), and quality-of-service (QoS) guarantees.
