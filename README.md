Archive_ICT Guide

# Template
There is a template for each category. 
Every category have the following propertie:
- categories: In this field are the categories of the note, can be more than one. The field must be filled with links to the corrispondent notes in the folder <strong>2 - Categories</strong>, and not plain text.
- topic@category: the topic under each categories, if there are more than one category add topic@category for each of them
- tags: the <strong>category/&lt;cat&gt;/&lt;topic&gt;</strong> tags are generated by the Category Tag Sync plugin from categories and topic@, do not edit them by hand

# Categories
This is the folder where is present the notes that are linked to the category field. 
Each main category field note has the tag <strong>categories</strong> and it's linked to its corrispondent <strong>.base</strong> file. To link a base, use: ![[filename.base]]
In this folder its also present the Topic folder where each catogory has its topic folder with their <strong>.base</strong> files.

# Base
The base file can be found in <strong>3 - Templates/Bases</strong>. 
Filter the base file in the following way:

```where categories.contains(link("Networking")) and !file.name.contains("Template")```

## Templater:
Template folder location: <strong>3 - Templates/Notes</strong>
Hotkey <strong>Alt+G</strong>: Templater: Open insert template modal
Folder templates (Trigger Templater on new file creation must be on):
- <strong>2 - Categories</strong> → <strong>3 - Templates/Notes/Codes/New Category</strong>: a new note in 2 - Categories scaffolds the whole category (topic folder, bases, note template, General topic)
- <strong>2 - Categories/Topics</strong> → <strong>3 - Templates/Notes/Codes/New Topic</strong>: a new note in 2 - Categories/Topics/&lt;Category&gt; scaffolds the topic and its base

Run from the insert modal (Alt+G):
- <strong>New Note</strong>: pick a category and topic and stamp the frontmatter
- <strong>Delete Category</strong> / <strong>Delete Topic</strong>: move a category or topic and its scaffolding to the system trash
- <strong>Link to Glossary</strong>: This template add a link to the selected word to the corrispondent word in the chosen glossary, the glossaries can be found in the folder 0 - Notes/Glossaries

## Category Tag Sync
Vault plugin in <strong>.obsidian/plugins/category-tag-sync</strong>. When a note's categories or topic@ properties change, it rewrites the note's category/ tags to match. Notes in 3 - Templates are never touched. To sync a note by hand run <strong>Category Tag Sync: Sync category tags in the active note</strong>.
