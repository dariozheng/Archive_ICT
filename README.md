Archive_ICT Guide

# Structure
- <strong>0 - Notes</strong>: every content note. New notes are created here.
	- <strong>0 - Notes/Glossaries</strong>: one glossary per category. Each term is a level 4 heading.
- <strong>1 - Excalidraw</strong>: the drawings, and the Excalidraw scripts in <strong>Scripts</strong>.
- <strong>2 - Categories</strong>: one note per category.
	- <strong>2 - Categories/Topics/&lt;Category&gt;</strong>: one note per topic of that category.
- <strong>3 - Templates</strong>: nothing in here is content.
	- <strong>Bases</strong>: the <strong>.base</strong> file of every category, <strong>Bases/Topics/&lt;Category&gt;</strong> for the topics, and <strong>Homepage.base</strong>.
	- <strong>Categories</strong>: the note template of each category (<strong>&lt;Category&gt; Template.md</strong>).
	- <strong>Notes/Codes</strong>: the Templater scripts.
- <strong>attachments</strong>: images, PDFs and every other attached file.
- <strong>Homepage.md</strong>: opens on startup.

# Template
There is a template for each category, in <strong>3 - Templates/Categories</strong>. They are not inserted by hand: <strong>New Note</strong> (see Templater) picks the template and fills it in.
Every template has the following properties:
- categories: the categories of the note, can be more than one. The field must be filled with links to the corresponding notes in the folder <strong>2 - Categories</strong>, and not plain text.
- topic@category: the topic under each category, as a link to a note in <strong>2 - Categories/Topics/&lt;Category&gt;</strong>. If there is more than one category add a topic@category for each of them (topic@networking, topic@security, ...). It can stay empty.
- tags: the <strong>category/&lt;cat&gt;/&lt;topic&gt;</strong> tags are generated by the Category Tag Sync plugin from categories and topic@, do not edit them by hand. Every other tag is free (see Tags).
- icon and iconColor: the icon shown next to the note, as an Iconize name (FasNetworkWired, SiCisco, LiLock, ...), and its colour as a quoted hex value ("#003791").
- last_update: the date of the last real change to the content. It is filled by hand.
- status: <strong>stub</strong> (placeholder, no real content yet), <strong>draft</strong> (in progress) or <strong>complete</strong>. New notes start as draft. Use this instead of tags like tobecompleted
- aliases: optional, the other names of the subject (BGP, ISE, ...).
- Distro: only in the Linux template, a link to the distribution (`[[Ubuntu]]`). The Ubuntu base filters on it.

# Categories
This is the folder with the notes that are linked in the categories field.
Each category note has the tag `categories` and embeds its corresponding <strong>.base</strong> file. To embed a base, use: `![[filename.base]]`
In this folder there is also the <strong>Topics</strong> folder, where each category has a folder with its topic notes. A topic note has the tag `topic` (`product` for Linux and Microsoft) plus its <strong>category/&lt;cat&gt;/&lt;topic&gt;</strong> tag, and embeds its own base.
Hardware and Systems do not have a topic folder yet, see Templater to scaffold it.

# Base
The base files are in <strong>3 - Templates/Bases</strong>, the topic ones in <strong>3 - Templates/Bases/Topics/&lt;Category&gt;</strong>.
A base is embedded by its file name, so two bases must never have the same name.
A category base is filtered in the following way:

```yaml
views:
  - type: table
    name: Table
    filters:
      and:
        - categories.contains(link("Networking"))
        - '!file.name.contains("Template")'
```

A topic base filters on the topic property instead. A property with <strong>@</strong> in its name needs the bracket syntax:

```yaml
        - note["topic@networking"].contains(link("WLAN"))
```

# Homepage
<strong>Homepage.md</strong> opens on startup and embeds the views of <strong>3 - Templates/Bases/Homepage.base</strong> (one view is embedded with `![[Homepage.base#Topics]]`):
- Topics: every topic note, grouped by category
- To finish: notes with status stub or draft
- Recently updated: the 10 most recently modified notes
- Needs triage: notes without a category or a status

The old Excalidraw homepage is kept as <strong>1 - Excalidraw/Homepage Map</strong>.

# Writing rules
- Bold is written with `<strong>` (Ctrl+B) and underline with `<u>` (Ctrl+U), not with Markdown asterisks: in Live Preview Markdown is not rendered inside a highlight, HTML is.
- Highlights are made with Highlightr (Ctrl+A), which wraps the selection in a coloured `<mark>`.
- Inside a table, a link with an alias needs its pipe escaped: `[[Note\|alias]]`. Without the backslash the pipe closes the cell and the rest of the row is shifted or lost.
- A tag written in a heading becomes part of the heading: `## Server Monitoring #complete` is linked as `[[#Server Monitoring complete]]`, and the link breaks when the tag changes. Keep tags out of the headings that are linked.
- Glossary terms are linked with <strong>Link to Glossary</strong> (see Templater). The term must exist as a heading in the glossary.

# Tags
- `category/<cat>/<topic>`: generated, never typed by hand.
- `categories`: the category notes. `topic` and `product`: the topic notes. `glossaries`: the glossary notes.
- `claude`: the note was created or written by Claude. Every new note made by Claude gets this tag. A note in <strong>0 - Notes</strong> without it is hand-written, and Claude changes it only after approval.
- `script`: on a Windows Server note it moves the note from the <strong>Windows Server</strong> base to the <strong>Windows Server Scripts</strong> base.
- Subject tags are free: certifications (`ccnp`, `encor/routing`, `scor/sise`), vendors and products (`cisco`, `palo_alto/ngfw`), projects (`PBA`).
- Section tags in the Palo Alto notes: `#configuration`, `#documentation`, `#troubleshooting`, `#complete`.

# Plugins

## Templater:
Template folder location: <strong>3 - Templates/Notes</strong>
Hotkey <strong>Alt+G</strong>: Templater: Open insert template modal
Folder templates (Trigger Templater on new file creation must be on):
- <strong>2 - Categories</strong> → <strong>3 - Templates/Notes/Codes/New Category</strong>: a new note in 2 - Categories scaffolds the whole category (topic folder, bases, note template, General topic)
- <strong>2 - Categories/Topics</strong> → <strong>3 - Templates/Notes/Codes/New Topic</strong>: a new note in 2 - Categories/Topics/&lt;Category&gt; scaffolds the topic and its base

Run from the insert modal (Alt+G):
- <strong>New Note</strong>: run it in a new empty note. Pick a category and a topic and it stamps the frontmatter. For a second category, add it to categories and add its topic@category by hand: the tags follow on their own.
- <strong>New Category</strong> / <strong>New Topic</strong>: run on an existing category or topic note, they create only the pieces that are missing (bases, topic folder, General topic) and leave the rest alone.
- <strong>Delete Category</strong> / <strong>Delete Topic</strong>: move a category or topic and its scaffolding to the system trash. Run it from a note that is not part of what is deleted. The notes in 0 - Notes are never touched, their links to it are left dangling.
- <strong>Link to Glossary</strong>: select a word and run it. It turns the word into a link to the heading with the same name in the chosen glossary. The glossaries are in the folder 0 - Notes/Glossaries, and their list is written in the script: a new glossary must be added there.
- <strong>ChangeHeaders</strong>: with an Excalidraw note open, resizes every text to three sizes (28, 22, 16). The drawing must be decompressed first (command <strong>Decompress current Excalidraw file</strong>).

## Category Tag Sync
Vault plugin in <strong>.obsidian/plugins/category-tag-sync</strong>. When a note's categories or topic@ properties change, it rewrites the note's category/ tags to match. Notes in 3 - Templates are never touched. To sync a note by hand run <strong>Category Tag Sync: Sync category tags in the active note</strong>.

## Highlightr
In Hotkeys bind <strong>Highlightr: Open Highlightr</strong> (Ctrl+A)

## Wrap with shortcuts
Three wrappers, each bound in Hotkeys:
- Name = <strong>bold</strong>, Start Tag = `<strong>`, End Tag = `</strong>` (Ctrl+B)
- Name = <strong>undeline</strong>, Start Tag = `<u>`, End Tag = `</u>` (Ctrl+U)
- Name = <strong>Link to Note with alias</strong>, Start Tag = `[[|`, End Tag = `]]` (Ctrl+P)

## Iconize and Notebook Navigator
Iconize reads the icon from the frontmatter: the icon in frontmatter option is on, with the field names <strong>icon</strong> and <strong>iconColor</strong>. The icon packs are in <strong>.obsidian/icons</strong>.
Notebook Navigator reads the same <strong>icon</strong> field, hides the <strong>attachments</strong> folder and hides the notes with the tag `glossaries`.

## Note Locker
Ctrl+L locks or unlocks the open note. A locked note cannot be edited by mistake.

## Homepage plugin
Opens <strong>Homepage.md</strong> on startup.

## Excalidraw
Excalidraw folder: <strong>1 - Excalidraw</strong>
Script folder: <strong>1 - Excalidraw/Scripts</strong>. The two <strong>Import_Headers_as_Links</strong> scripts ask for a note and draw its headings as boxes linked to it, with or without a preview of the text.

## Others
- Advanced Tables: Tab and Enter move between the cells of a table.
- Minimal Theme Settings and Style Settings, with the CSS snippet <strong>headers</strong> for the colour and size of the headings.
- Git: backup of the vault. It needs git installed and the vault to be a git repository.
- Find orphaned images: lists the images that no note uses.
- Linked Note Exporter: exports a note together with the notes and files it links.
- Dataview, Metadata Menu and XLSX Viewer are installed, but no note uses them at the moment.
